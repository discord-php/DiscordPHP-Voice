State.php : 31

Per-connection DAVE E2EE state.

Owns the MLS session lifetime, protocol version, passthrough mode, and all key-ratchet / decryptor / encryptor handles. Destruction ordering matters: encryptor/decryptors must be destroyed before key-ratchets, before the session (enforced by close() and __destruct()).

State machine summary: prepareProtocolVersion() → passthroughMode=true (waiting for transition) executeTransition() → passthroughMode=false (media E2EE active) resetProtocolState() → passthroughMode=true (all handles freed)
