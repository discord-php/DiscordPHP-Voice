playFile()

ManagesPlayback.php : 58

Plays a file/url on the voice stream.

public playFile(string $file[, int $channels = 2 ]) : PromiseInterface

FFmpeg is used to decode the file, so any format ffmpeg supports is accepted (e.g. WAV, OGG Opus, MP3, FLAC). Raw PCM files (.pcm) are NOT supported here because ffmpeg cannot auto-detect the format — use playPcmFile() instead.

Parameters
$file : string

The file/url to play.

$channels : int = 2

Deprecated, Discord only supports 2 channels.

playPcmFile()

ManagesPlayback.php : 189

Plays a raw PCM file on the voice stream.

public playPcmFile(string $path[, int $channels = 2 ][, int $audioRate = 48000 ]) : PromiseInterface

This is a convenience wrapper around playRawStream() for files saved as raw signed 16-bit little-endian PCM (e.g. recordings produced by record() with RecordingFormat::PCM).

Parameters
$path : string

Absolute or relative path to the raw PCM file.

$channels : int = 2

Number of audio channels (default: 2 = stereo).

$audioRate : int = 48000

Sample rate in Hz (default: 48000).
